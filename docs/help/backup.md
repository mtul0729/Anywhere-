# 备份与恢复

Anywhere- 的备份目标是保存卡片、页面和分类配置，方便升级、换机或误删后恢复。备份不是完整的应用数据镜像。

## 本地备份

在 **设置 → 备份和恢复 → 备份** 中点击“创建新的备份文件”：

1. 应用打开系统文件创建界面。
2. 文件名默认为 `Anywhere-Backups-<日期>.awbackups`。
3. 选择保存位置并确认。
4. 看到“备份成功”表示文件已写入。

备份内容会序列化为 JSON，再用应用内置密钥加密后写入文件。请保留 `.awbackups` 后缀，恢复时更容易识别。

## 备份包含什么

包含：

- 卡片名称、类型、参数、描述、分类和时间戳。
- 页面列表和页面优先级。
- 卡片颜色、执行方式和部分标志位。

不包含：

- **图片卡片**。
- **文件卡片**。
- 卡片的自定义图标 URI。
- 应用设置、工作模式、WebDAV 密码等偏好数据。
- 动态 Shortcuts 和桌面快捷方式。

图片和文件卡片被跳过，是因为它们依赖本地文件 URI 或持久化访问权限，换机后通常无法使用。备份时应用还会清空导出卡片的自定义图标 URI。

## 从文件恢复

在 **设置 → 备份和恢复 → 恢复** 中选择一个 `.awbackups` 文件：

1. 应用读取并解密文件。
2. 恢复卡片和页面。
3. 如果卡片分类对应的页面不存在，会自动创建页面。
4. 看到“恢复成功”表示写入完成。

恢复是追加数据，不是清空数据库后替换。重复恢复同一份文件可能产生重复卡片。恢复前建议先创建当前状态的备份。

如果文件不是有效备份、密钥不匹配或内容损坏，会提示“备份文件格式错误”。旧版本中结构不兼容的备份也可能无法恢复。

## 分享配置

“分享配置”会导出与本地备份相同的内容，并显示：

- 一段加密配置文本。
- 可复制到剪贴板的按钮。

复制后可以通过聊天、笔记或其他方式发送。对方在 **设置 → 备份和恢复 → 应用配置** 中粘贴文本，即可恢复卡片和页面。

分享配置同样不包含图片卡片、文件卡片和自定义图标 URI。不要把包含敏感 Shell、账号 Scheme 或内部地址的配置公开分享。

## 分享单张卡片

在卡片编辑器菜单中选择“分享此卡片”：

- 应用生成 `anywhere://share/<encrypted>` 链接。
- 对话框同时显示二维码，便于另一台设备扫描。
- 复制链接后，在已安装 Anywhere- 的设备上打开，会进入卡片编辑器并导入该卡片。

单张分享会清空分类和自定义图标 URI，并只包含这一张卡片。图片卡片和文件卡片不能通过此入口分享。

## WebDAV 云备份

在 **设置 → 备份和恢复 → 云备份** 中填写：

- WebDAV 域名。
- 用户名。
- 密码。

三项都填写后，可以：

- **立即备份**：把当前卡片上传到 WebDAV。
- **恢复备份文件**：列出 WebDAV 上的备份并选择恢复。
- **自动备份**：卡片发生改动后，下次进入主界面时触发备份。

远程目录固定为：

```text
Anywhere-/Backup/
```

备份文件名包含日期和版本号，例如：

```text
Anywhere-Backups-2026-10-27-2.5.6-alpha.2.awbackups
```

手动备份会创建目录并上传；自动备份最多保留 25 个文件，超过后按文件名排序删除最旧的备份。

## WebDAV 常见问题

### 提示检查配置

域名、用户名或密码为空时不会发起请求。确认三项都已保存，并检查域名是否包含正确的协议和路径。

### 备份失败

常见原因：

- WebDAV 服务不可达或证书无效。
- 用户名/密码错误。
- 服务器不允许创建 `Anywhere-/Backup/` 目录。
- 代理、防火墙或客户端限制。
- 服务器对文件名中的空格、冒号或版本号有限制。

应用会显示底层异常信息；先检查服务器日志，再尝试用其他 WebDAV 客户端上传同名文件。

### 自动备份没有触发

自动备份需要：

- 已填写完整的 WebDAV 配置。
- 已开启“自动备份”。
- 卡片确实发生了改动。
- 应用回到主界面并有机会启动备份服务。

自动备份是“改动后触发”，不是定时任务。应用被系统彻底停止或长期不打开时不会运行。

## 恢复失败或数据丢失

- 确认选择的是 `.awbackups` 文件，不是普通 JSON、图片或 APK。
- 尝试用同一 fork 的正式版本恢复；不同签名不影响备份解密，但旧版本结构可能不兼容。
- 恢复前先复制原始备份文件，不要覆盖或反复重写。
- 如果应用无法启动，先保留原 APK 和数据，再通过 ADB 抓取日志，不要直接卸载覆盖。

应用数据库和备份密钥不是可互换的跨应用格式。不要尝试用其他 Anywhere- fork 或第三方工具修改备份文件。
