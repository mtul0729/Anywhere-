# 快速上手

## 1. 首次启动

第一次打开 Anywhere- 时，会进入设置向导：

1. 选择工作模式。
2. 根据所选模式授予 Root、Shizuku、悬浮窗和 MIUI 后台弹出权限。
3. 点击右上角完成。未授予全部权限时仍可进入，但部分功能会不可用。

如果你只需要创建普通卡片，选择 **URL Scheme** 模式即可，不需要 Root 或 Shizuku。三种工作模式的详细区别见 [权限与工作模式](permissions.md)。

首次进入主页时，应用会插入一张“帮助文档”卡片，并提示你创建第一张卡片。这张卡片只是一个普通 URL Scheme 卡片，可以删除或重新创建。

## 2. 认识主界面

- 卡片区域：点击卡片执行动作；长按卡片可进入编辑、选择等操作。
- 右下角按钮：打开添加入口，包含添加卡片、Collector、活动列表、扫码合集、云端规则和其它应用快捷方式。
- 顶部菜单：排序、设置；多选模式下会出现删除、移动和创建桌面快捷方式。
- 左侧抽屉：启用“分页”后用于切换和管理页面。

## 3. 创建第一张卡片

1. 点击右下角按钮。
2. 选择“添加卡片”。
3. 在卡片类型中选择 **URL Scheme**。
4. 填写卡片名称和 URL Scheme，例如：

   ```text
   https://example.com
   ```

5. 点击右上角“测试”确认能打开目标。
6. 点击底部完成按钮保存。

保存后，点击主页上的卡片即可再次执行。URL Scheme 也可以是 `scheme://...` 或 `#Intent;...` 形式；后者会按 Android Intent URI 解析。

## 4. 编辑和管理卡片

长按卡片或从编辑菜单进入卡片编辑器后，可以：

- 修改名称、描述和卡片参数。
- 测试当前配置。
- 自定义卡片颜色或图标。
- 将卡片移动到其他页面。
- 分享卡片链接或二维码。
- 添加动态 Shortcut 或桌面快捷方式。
- 删除卡片。

图片和文件卡片的编辑器不显示“测试”按钮；文件卡片也不能直接分享。图片卡片和文件卡片不会包含在备份文件中。

## 5. 添加桌面快捷方式

1. 打开卡片编辑器。
2. 打开右上角菜单。
3. 选择“添加桌面快捷方式”。
4. 确认图标和名称。
5. 按启动器提示确认。

Android 8.0 及以上通常使用系统的 pinned shortcut API。请求成功后会提示“已请求创建，请在启动器中确认”；启动器确认后才提示“桌面快捷方式已创建”。不同启动器可能不弹确认框，也可能直接把图标放到桌面。

如果图标没有出现，先检查启动器是否支持固定快捷方式，再检查是否启用了“使用废弃的方法创建快捷方式”。详细说明见 [快捷方式](shortcuts.md)。

## 6. 备份

在 **设置 → 备份和恢复** 中可以：

- 创建本地 `.awbackups` 文件。
- 从文件恢复。
- 复制或分享加密配置。
- 配置 WebDAV 并手动或自动备份。

升级、换机或卸载前先备份。备份不包含图片卡片、文件卡片和自定义图标 URI；详细限制见 [备份与恢复](backup.md)。

## 7. 日常使用建议

- 普通卡片优先使用 URL Scheme，兼容性通常比指定 Activity 更好。
- Shell、无障碍和冻结应用相关功能先确认工作模式与解冻方式。
- 修改重要卡片前先备份；恢复会追加数据，不应当把它当成“清空后重装”的替代品。
- 发布版和 debug 版签名、包名不同，不能互相覆盖安装。
