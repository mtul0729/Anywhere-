# 快捷方式

Anywhere- 涉及两类容易混淆的快捷方式：

- **动态 Shortcuts**：显示在长按应用图标后的系统快捷菜单中，最多约 3 个。
- **桌面快捷方式（pinned shortcut）**：直接固定到桌面，可单独设置名称和图标。

两者是独立功能。“清除 Shortcuts”只清除动态 Shortcuts，不会删除桌面快捷方式。

## 动态 Shortcuts

在卡片编辑器右上角菜单中：

- 选择“添加 Shortcuts”把当前卡片加入系统动态快捷菜单。
- 已加入的卡片会显示“删除 Shortcuts”，再次选择即可移除。

限制和行为：

- 只在 Android 7.1 及以上显示此功能。
- 动态 Shortcuts 最多约 3 个；达到上限后会提示仍要添加。
- 修改卡片名称时，已加入的动态 Shortcut 会同步更新。
- 图片卡片使用图片 URI 作为快捷动作；其他卡片保存真实实体 ID。

动态 Shortcuts 是否显示、显示顺序和数量由启动器决定，不同 ROM 可能不同。

## 桌面快捷方式

打开卡片编辑器，在右上角菜单中选择“添加桌面快捷方式”：

1. 修改快捷方式名称。
2. 点击图标选择本地图片；不修改则使用卡片图标。
3. 点击确认。
4. 按启动器提示确认固定。

Android 13 及以上使用系统的 `requestPinShortcut`：

- 请求发出后提示“已请求创建，请在启动器中确认”。
- 启动器真正创建成功后，应用提示“桌面快捷方式已创建”。
- 部分启动器不会显示确认界面，而是直接添加。
- 启动器不支持固定快捷方式时，请求可能没有结果。

桌面快捷方式使用独立 ID `pinned_<entityId>`，但 Intent 中仍保存真实实体 ID；这样不会与动态 Shortcuts 的 ID 冲突，也不会因为显示 ID 带前缀而找不到卡片。

## 多选创建

在主页长按进入多选模式后，部分系统会显示“添加桌面快捷方式”。选择多张卡片并确认后，应用会依次请求固定快捷方式，每个请求之间等待约 200 ms。

启动器可能逐个弹确认框，也可能批量处理。不要连续快速重复请求，以免启动器去重或忽略。

## 清除 Shortcuts

**设置 → 清除 Shortcuts** 会：

- 删除所有动态 Shortcuts。
- 清空应用内记录的动态快捷方式列表。

它不会：

- 删除已经固定在桌面的快捷方式。
- 删除卡片本身。
- 撤销图片快捷方式的文件访问权限。

桌面快捷方式需要在桌面或启动器的快捷方式管理中删除。

## 判断是否创建成功

### 从界面判断

- 看到“桌面快捷方式已创建”：系统回调已触发。
- 只看到“已请求创建，请在启动器中确认”：请求已发出，但启动器尚未确认。

### 从系统记录判断

在已连接 ADB 的设备上执行：

```bash
adb shell dumpsys shortcut | grep -C 4 'pinned_'
```

应能看到类似记录：

```text
Pinned: pinned_<entityId>
ShortcutInfo {id=pinned_<entityId>
```

Intent extras 中的 `shortcutsId` 应是真实实体 ID，不带 `pinned_` 前缀。

### 点击测试

点击桌面图标后：

- URL Scheme 卡片进入浏览器或目标 App，是正常结果。
- 图片卡片打开图片对话框。
- Shell 卡片执行命令；如果没有权限，会提示切换工作模式或权限错误。

如果图标存在但点击无反应，先确认卡片本身还能从主页打开，再检查快捷方式是否被启动器缓存为旧配置。

## 图标和角标

部分 ROM 会在桌面快捷方式图标上叠加应用角标。可以在 **设置 → 实验室 → 透明图标** 中尝试规避；这不是所有启动器都支持的通用修复。

快捷方式名称不能为空；留空时应用会使用一个空格作为兜底，但建议填写可识别名称。
